## Introduction

Gurgle GuLang is designed to make programming accessible to everyone. With a focus on readability and ease of use, Gurgle GuLang allows developers to create applications without the steep learning curve associated with many modern languages. The Gurgle_Gu repository acts as a gateway, providing users with a straightforward path to start their journey with Gurgle GuLang.

## Features

- **Simplicity**: Gurgle GuLang syntax is clean and easy to understand, making it suitable for beginners.
- **Efficiency**: Designed for performance, Gurgle GuLang executes tasks quickly.
- **Community-Driven**: The language is developed with input from users, ensuring it meets the needs of real-world applications.
- **Documentation**: Comprehensive guides and examples are available to help you get started.

## Installation

To install Gurgle GuLang, you can download the latest release from our [Releases section](https://github.com/GGabrielAmorim/Gurgle_Gu/releases). Once you have downloaded the file, follow these steps:

1. Extract the contents of the downloaded file.
2. Open your terminal or command prompt.
3. Navigate to the extracted folder.
4. Run the installation script using the command:
   ```bash
   ./install.sh
   ```

## Usage

Once installed, you can start using Gurgle GuLang by creating a new file with the `.gg` extension. Here’s a simple example to get you started:

```gurgle
print("Hello, Gurgle GuLang!")
```

To run your Gurgle GuLang program, use the command:

```bash
gurgle run yourfile.gg
```

This command will execute your program and display the output in the terminal.
